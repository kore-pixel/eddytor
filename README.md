# eddytor ✦

글쓰기와 강의 필기를 위한 문서 편집 앱이에요. 스페이스(폴더·문서), 글꼴 3종, 서식, 글자 수, PDF/TXT 내보내기, 링크 공유, 로그인 동기화를 지원해요. 설치할 것 없이 웹(GitHub Pages)에서 돌아가고, 폰에는 앱처럼 설치(PWA)할 수 있어요.

## 파일 구성

```
index.html / style.css / app.js / sync.js   앱 본체
fonts.css + fonts/                            문서 폰트 3종 (프리텐다드·코펍월드돋움·나눔명조) — 파일이 같이 들어 있어서 인터넷 주소에 기대지 않아요
my-fonts.css                                  앱 화면용 폰트(아스타산스·펴진고딕) 붙여넣는 곳 — 내가 직접 채운 파일
config.js                                     Supabase 주소·키 — 내가 직접 채운 파일
supabase.sql                                  서버 표 만들기 (SQL Editor에 붙여넣고 Run)
sw.js / manifest.webmanifest / icon-*         설치(PWA)용
assets/star-chrome*.png                       쇠 질감 별
```

## 1. GitHub에 올리기 (업데이트)

1. 저장소(`kore-pixel/eddytor`) → **Add file → Upload files**
2. 압축을 푼 파일·폴더를 모두 끌어다 놓기 (`fonts/`, `assets/` 폴더 포함)
3. ⚠️ **`config.js`와 `my-fonts.css`는 올리지 마세요.** 이미 내 설정이 들어 있는 파일이라 덮어쓰면 사라져요. (이 압축 파일에는 아예 넣지 않았어요. 단, 예전 `config.js`가 `BYEOL_CONFIG` 이름을 써도 그대로 동작해요.)
4. **Commit changes** → 1~2분 뒤 https://kore-pixel.github.io/eddytor/ 에 반영돼요.
5. 안 바뀐 것 같으면 `Ctrl+Shift+R`(폰은 앱 완전 종료 후 다시 열기). 크롬의 "쿠키 및 사이트 데이터"는 지우지 마세요 — 문서가 이 기기에 저장돼 있어요.

## 2. 서버 연결 (공유 + 로그인 동기화)

이미 Supabase 프로젝트와 `config.js`를 만들어 두셨다면 **아래 두 가지만** 하면 돼요.

**① 표 추가하기**  
Supabase → 왼쪽 **SQL Editor → New query** → `supabase.sql` 내용 전체를 붙여넣고 **Run**.  
(여러 번 실행해도 괜찮아요. 기존 공유 기능은 그대로 유지돼요.)

**② 메일 확인 끄기** (이게 켜져 있으면 가입할 때 메일 인증이 필요해요)  
Supabase → **Authentication → Sign In / Providers → Email** → **Confirm email** 끄기 → Save.

그다음 앱 왼쪽 아래 **로그인 · 동기화** → 이메일·비밀번호로 **가입하기**. 그 뒤로는 문서를 고칠 때마다 서버에 자동 저장되고, 다른 기기에서 같은 계정으로 로그인하면 문서가 그대로 나와요.

- 이 기기에 이미 있던 문서는 첫 로그인 때 서버로 올라가요.
- 인터넷이 없을 때 쓴 내용은 연결되면 자동으로 올라가요.
- 같은 문서를 두 기기에서 동시에 고치면 **나중에 고친 쪽**이 남아요. 한 문서는 한 기기에서 쓰는 걸 권해요.
- 비밀번호 재설정 메일은 아직 없어요. 비밀번호는 꼭 기억해 두세요. (Supabase 대시보드 → Authentication → Users 에서 직접 바꿀 수도 있어요.)

### config.js 처음 만드는 경우
```js
window.EDDYTOR_CONFIG = {
  supabaseUrl: 'https://프로젝트ID.supabase.co',
  supabaseAnonKey: 'sb_publishable_...',
};
```
Supabase → Project Settings → API (또는 API Keys)에서 URL과 publishable 키를 복사해요. **secret / service_role 키는 절대 넣지 마세요.**

## 3. 폰트

| 폰트 | 어디에 쓰나 | 상태 |
|---|---|---|
| 프리텐다드 · 코펍월드돋움 · 나눔명조 | 문서 안 글씨 | `fonts/`에 들어 있어요 (바로 동작) |
| 아스타산스 · 펴진고딕 | 앱 화면(제목·버튼 / 본문) | `my-fonts.css`에 직접 붙여넣어 둔 것 |

> 문서 글꼴이 프리텐다드로만 나오던 문제는, 폰트를 외부 주소에서 받아오다 실패하던 게 원인이라 폰트 파일을 앱에 함께 넣는 방식으로 바꿨어요.  
> 코펍월드돋움은 한국출판인회의 배포 폰트예요. 사용 범위(`fonts/licenses/`)를 한 번 확인해 주세요. 프리텐다드·나눔명조는 SIL OFL 1.1이에요.

## 4. 쓰는 법 요약

- **스페이스 홈**: 문서를 열지 않았을 때 보이는 첫 화면. 최근 문서·폴더가 카드로 나와요. 왼쪽 위 eddytor 로고를 누르면 언제든 돌아와요.
- **새 문서 / 새 폴더**: 위쪽 ＋ 버튼은 항상 **스페이스 최상위**에 만들어요. 폴더 안에 만들려면 폴더의 `⋯` → "이 폴더에 새 문서".
- **문단 들여쓰기**: 도구 줄의 체크박스를 켜면 모든 문단의 첫 줄이 들여쓰기 돼요. 문서마다 따로 저장돼요(중앙·오른쪽 정렬 문단은 제외). 공유·HTML·TXT에도 반영돼요.
- **검색**: 왼쪽 위 검색창 — 제목과 본문을 함께 찾아요.
- **공유**: 문서를 열고 "공유" → 켜면 링크 생성. 고치면 자동 반영, 끄면 링크가 즉시 닫혀요.
- **내보내기**: PDF(인쇄 창에서 "PDF로 저장") / TXT / HTML.
- **백업 · 복원**: 문서 전체를 파일로 내려받거나 불러와요.

## 4-2. 펜 필기 (S펜)

도구 줄의 **✎ 필기**를 누르면 필기 모드가 돼요. 문서 위 어디에나 쓸 수 있고, 아래쪽 끝에 가까워지면 페이지가 자동으로 늘어나요.
- **펜 / 형광펜 / 지우개**: 지우개는 "획 지우기"(닿은 획을 통째로)와 "부분 지우기"(닿은 부분만) 중에서 고르고, 슬라이더로 크기를 정해요. S펜 지우개 쪽(버튼)도 인식돼요.
- **선택**: 점선 올가미로 감싸면 선택돼요. 한 획을 톡 눌러도 선택돼요. 선택하면 이동·크기 조절(모서리)·회전(위쪽 동그라미)이 돼요.
  - 올가미가 획의 일부만 걸칠 때: "획 전체"(기본) 또는 "잘라서"(걸친 부분만 잘라 선택) 중에서 골라요.
- **스타일 변경**: 선택한 획에서 색·굵기를 바꾸거나 "펜으로 / 형광펜으로" 바꿔요. 복제·삭제도 돼요.
- 필기 전용 실행 취소(↶ ↷, Ctrl+Z)가 따로 있어요. 손가락은 화면 스크롤, 펜(마우스)은 쓰기예요.
- ⚠️ 필기는 페이지 위치에 고정돼요. 위쪽 글을 고치면 글만 움직이고 필기는 그대로 있어요. 공유 링크에는 필기가 아직 안 보여요. PDF 내보내기에는 보이지만 위치가 조금 어긋날 수 있어요.
- 필기를 쓰려면 `supabase.sql`을 다시 실행해야 동기화돼요(맨 아래 [3]).

## 4-3. 사진 넣기

도구 줄의 **🖼 사진**(필기 도구 줄에도 있어요)으로 사진을 골라요. 클립보드의 사진은 필기 모드에서 Ctrl+V로도 붙여넣어요.
- 사진은 긴 변 1600px 이하로 줄여서 이 기기의 IndexedDB에 저장돼요. 문서에는 위치·크기만 저장돼요.
- **선택** 도구로 끌어서 옮기고, 모서리로 크기, 위쪽 동그라미로 회전해요. 복제·삭제도 돼요. 사진 위에 펜으로 필기할 수 있어요.
- ⚠️ 사진 그림 자체는 서버로 동기화되지 않아요. 다른 기기에서는 "사진이 이 기기에 없어요" 자리표시가 보여요. 기기를 옮기거나 브라우저 데이터를 지울 때는 **백업 · 복원**의 백업 파일을 쓰세요(사진도 같이 담겨요).

## 4-4. 녹음 + 필기 시점 연동

도구 줄의 **녹음**을 누르면 녹음 패널이 열려요. **녹음 시작** → 강의를 들으며 글을 쓰거나 필기를 하면, 쓴 시점이 녹음의 몇 초인지 같이 저장돼요. (일시정지한 시간은 빠져요)
- **다시 듣기**: 패널에서 "글을 누르면 그 시점으로"가 켜져 있으면 글(문단)을 눌러 그 시점부터 들어요. 필기는 필기 모드의 **듣기** 도구로 획을 눌러요. 재생 중에는 아직 안 쓴 필기가 흐리게 보이고, 지금 재생 중인 문단에 노란 띠가 보여요.
- 녹음마다 이름 바꾸기 · 저장(파일로 내려받기) · 삭제가 돼요. 재생 속도는 오디오 막대의 ⋮ 메뉴에서 바꿔요.
- 시점 표시는 문단 단위예요. 한 문단을 오래 쓰면 그 문단을 처음 쓴 시점으로 이동해요.
- ⚠️ 녹음 파일은 이 기기의 브라우저에만 저장돼요(서버 동기화 없음, 백업 파일에도 안 들어가요). 중요한 녹음은 **저장** 버튼으로 파일을 내려받아 두세요. 브라우저 데이터를 지우면 녹음도 사라져요.
- ⚠️ 녹음 중에는 화면을 켜 두세요. 화면이 꺼지거나 다른 앱으로 가면 폰·태블릿이 녹음을 멈출 수 있어요(가능한 기기에서는 화면 꺼짐을 막아 둬요). 녹음 중 앱을 닫으면 그 녹음은 저장되지 않아요.
- 마이크 권한을 허용해야 해요(https 주소에서만 동작).

## 4-5. PDF 불러오기 (강의 자료에 필기)

도구 줄의 **PDF**(필기 도구 줄에도 있어요)로 PDF 파일을 골라요. 두 가지 방식 중에서 골라요.
- **글자를 살려서 (권장)**: PDF 원본을 이 기기에 한 번 저장하고, 화면에 보이는 쪽만 그려요(쪽이 많아도 가벼워요). 문서 글 아래에 위아래로 이어 붙고, 위치는 옮길 수 없어요. 이렇게 쓸 수 있어요.
  - 글자 선택·복사 → 글자를 선택하면 나오는 **형광펜 칠하기**로 줄 따라 칠하기(필기 획이라 나중에 선택·지우기 가능)
  - **PDF 검색**(도구 줄, PDF를 넣은 문서에만 보여요): 찾는 말이 있는 쪽 목록 → 누르면 그 쪽으로 이동
  - ✎ 필기를 켜면 쪽 위에 펜으로 쓸 수 있어요(필기 중에는 글자 선택이 꺼져요). 녹음·시점 연동도 그대로 돼요.
  - PDF 삭제는 첫 쪽 오른쪽 위의 "PDF 삭제" 버튼. 쪽 번호를 골라 일부만 가져올 수도 있어요.
- **그림으로**: 각 쪽을 그림(JPEG)으로 바꿔서 사진처럼 옮기고 지울 수 있어요. 글자 선택은 안 돼요. 스캔한 PDF나 쪽을 자유롭게 배치할 때 써요. 한 번에 80쪽까지예요.
- ⚠️ PDF 원본과 쪽 그림은 이 기기에만 저장돼요(서버 동기화·백업 파일에 원본은 안 들어가요). 다른 기기에서는 "이 기기에 PDF 파일이 없어요"로 보여요. 원본 PDF 파일은 따로 보관해 두세요.
- ⚠️ 글자 살리기는 위쪽 글이 길어지면 PDF와 겹칠 수 있어요. PDF가 든 문서는 글을 위에 짧게 쓰는 걸 권해요. 내보내기(PDF)에는 화면에 그려진 쪽만 들어가서 불러온 PDF 쪽은 정확히 안 나와요.
- 링크(주소 클릭)와 PDF 안의 메모·양식은 아직 안 돼요. 암호 걸린 PDF는 못 읽어요.
- `vendor/pdfjs/`는 PDF를 읽는 Mozilla pdf.js(Apache-2.0)와 한글 글꼴 변환표예요. 지우지 마세요.

## 5. 폰에 설치 / APK 만들기

**그냥 설치(권장)**: 폰 크롬에서 앱 주소를 열고 메뉴 → "홈 화면에 추가" 또는 "앱 설치".  
크롬이 "이미 설치됨/앱을 열 수 없음"이라고 하면: 설정 → 앱에서 예전에 만든 같은 주소의 앱(별문서 등)을 삭제하고, 크롬 **캐시만** 지운 뒤 다시 설치해 보세요. 그래도 안 되면 "바로가기 추가"로 쓸 수 있어요.

**APK 만들기**: https://www.pwabuilder.com 에 앱 주소를 넣고 **Package for stores → Android**. 내려받은 압축 안의 `.apk`를 폰으로 옮겨 설치(출처 불명 앱 허용 필요)하거나, 구글 플레이 등록용 `.aab`로 쓸 수 있어요.

## 6. 앱을 고쳐서 올릴 때

`sw.js` 맨 위 `VERSION` 숫자를 올려 주세요(`eddytor-v1` → `eddytor-v2`). 안 올려도 최신 파일을 먼저 받아오지만, 오프라인 저장본을 새로 만들려면 올리는 게 확실해요.

## 개인정보·보안 메모

- 문서는 이 기기(브라우저)에 저장되고, 로그인하면 내 Supabase 프로젝트에도 저장돼요. 다른 사람은 내 문서를 읽을 수 없도록 행 단위 보안(RLS)이 걸려 있어요.
- 공유 링크는 "링크를 아는 사람은 누구나 열람" 방식이에요. 공유 문서는 서버에서 따로 사본이 공개돼요.
- 공개 키(publishable/anon)는 노출돼도 되지만 secret/service_role 키는 절대 올리지 마세요.
