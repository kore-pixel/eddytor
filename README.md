# 별문서 ✦

글쓰기와 강의 필기를 위한 문서 편집 앱이에요. 서버 없이 브라우저에서 돌아가고, GitHub Pages에 올리면 무료로 쓸 수 있어요. 폰 홈 화면에 설치하면 앱처럼 열려요.

## 있는 기능

- **스페이스**: 폴더와 문서를 만들고, 이름 바꾸기·이동·삭제, **세부정보(생성일·수정일 등)**
- **문서 글꼴**: 프리텐다드 / 코펍월드돋움 / 나눔명조
- **서식**: 굵게·기울임·밑줄·취소선, 글자 크기, **자간**, **줄간격**, 글자 색, 하이라이트, 왼쪽·가운데·오른쪽·양쪽 정렬
- 글자 수(공백 포함/제외, 선택한 부분), 실행 취소·다시 실행
- 내보내기: **PDF · TXT · HTML**, 전체 백업/복원(JSON)
- **링크 공유**: 비공개 ↔ 링크로 공개 게시 (Supabase 무료 서버 사용, 아래 설정)
- 오프라인에서도 열려요 (PWA)

문서는 **이 기기의 브라우저에 저장**돼요. 기기를 바꾸거나 브라우저 데이터를 지우기 전에는 사이드바 아래 **백업 · 복원**으로 백업해 두세요.

---

## 1. GitHub Pages에 올리기 (10분)

1. GitHub에서 새 저장소를 만들어요 (예: `byeol-docs`, Public).
2. 이 폴더의 파일을 **전부** 올려요 (`.nojekyll` 포함 — 숨김 파일이니 놓치지 마세요). 웹에서 *Add file → Upload files*로 끌어다 놓으면 돼요.
3. 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 저장해요.
4. 1~2분 뒤 `https://내아이디.github.io/byeol-docs/` 에서 열려요.

> 앱을 고쳐서 다시 올렸는데 예전 모습이 보이면 `sw.js` 맨 위의 `VERSION` 숫자를 올려 주세요.

## 2. 폰에 앱으로 설치하기

- **안드로이드(크롬)**: 주소를 연 뒤 메뉴 ⋮ → **앱 설치** (또는 홈 화면에 추가)
- **아이폰(사파리)**: 공유 버튼 → **홈 화면에 추가**
- **컴퓨터(크롬/엣지)**: 주소창 오른쪽의 설치 아이콘

## 3. 폰트 설정

| 폰트 | 어디서 불러오나 | 할 일 |
|---|---|---|
| 프리텐다드 | jsDelivr CDN (OFL 라이선스) | 없음 |
| 나눔명조 | Google Fonts (OFL 라이선스) | 없음 |
| 코펍월드돋움 | jsDelivr의 `font-kopubworld` 패키지 (한국출판인회의 배포 서체) | 없음 |
| 아스타산스 / 느좋체 (앱 화면용) | **직접 넣어야 해요** | 아래 참고 |

**아스타산스·느좋체 넣기**: [눈누](https://noonnu.cc)에서 두 폰트를 찾아 라이선스(웹 사용 가능 여부)를 확인하고 내려받은 뒤, `fonts/` 폴더를 만들어 이렇게 이름을 맞춰 넣어요.

```
fonts/AstaSans.woff2   (또는 .woff)
fonts/Neujoche.woff2   (또는 .woff)
```

파일이 없으면 프리텐다드로 자동 대체돼서 앱은 그대로 잘 돌아가요. (파일 이름을 바꾸기 싫다면 `style.css` 맨 위 `@font-face`의 `url()`을 수정하세요.) ttf/otf만 있다면 [CloudConvert](https://cloudconvert.com/ttf-to-woff2) 같은 곳에서 woff2로 바꿔 쓰면 용량이 줄어요.

> 코펍월드돋움·아스타산스·느좋체는 각자 배포처의 라이선스를 따라요. 눈누 상세 페이지의 사용 범위를 꼭 한 번 확인해 주세요.

## 4. 공유 서버 연결 (링크로 공개 게시)

GitHub Pages는 정적 사이트라 “공개/비공개를 켜고 끄는” 일을 못 해요. 그래서 무료 [Supabase](https://supabase.com)를 작은 우체통처럼 써요. **공유를 안 쓸 거면 이 단계는 건너뛰어도 돼요.**

1. supabase.com에 가입 → **New project** (이름·DB 비밀번호 아무거나, 지역은 Northeast Asia (Seoul) 추천)
2. 왼쪽 **SQL Editor → New query**에 이 폴더의 `supabase.sql` 내용을 **통째로 붙여넣고 Run**
3. **Project Settings → API**(또는 API Keys)에서 두 값을 복사해요.
   - Project URL → `https://xxxx.supabase.co`
   - **anon public** 키 (또는 `sb_publishable_…`)
   - ⚠️ `service_role` / secret 키는 절대 넣지 마세요.
4. `config.js`를 열어 두 값을 채우고 GitHub에 다시 올려요.

```js
window.BYEOL_CONFIG = {
  supabaseUrl: 'https://xxxx.supabase.co',
  supabaseAnonKey: 'sb_publishable_...',
};
```

### 공유가 동작하는 방식

- 문서의 **공유** 버튼에서 “링크로 공개 게시”를 켜면 `…/byeol-docs/?s=랜덤ID` 링크가 생겨요. 링크를 받은 사람은 로그인 없이 **읽기 전용**으로 볼 수 있어요.
- 공개 중인 문서를 고치면 1~2초 뒤 자동으로 반영돼요.
- 스위치를 끄면 서버에서 문서가 삭제되고 링크가 바로 닫혀요.
- 누구나 서버의 문서 **목록을 볼 수는 없어요**. 링크의 ID를 알아야만 그 문서 하나를 읽을 수 있고, 수정·삭제는 만든 기기에 저장된 비밀 토큰이 있어야 해요. (그래서 **브라우저 데이터를 지우면 그 문서의 공개 해제를 못 해요.** 이럴 땐 Supabase **Table Editor → shared_docs**에서 해당 행을 직접 지우세요.)
- 공유 화면에는 글꼴·크기·색·정렬 같은 서식만 남기고 나머지는 걸러서(DOMPurify) 보여줘요.
- Supabase 무료 플랜은 일정 기간 접속이 없으면 프로젝트가 일시 중지될 수 있어요. 대시보드에서 다시 켤 수 있어요.

## 5. APK로 만들고 싶다면

PWA를 그대로 안드로이드 앱(APK/AAB)으로 감싸는 방법이에요. 먼저 **1번(GitHub Pages 배포)이 끝나 있어야** 해요. 폰에 “앱 설치”만 해도 충분하다면 이 단계는 필요 없어요.

### 가장 쉬운 방법: PWABuilder (코딩 없음, 무료)

1. [pwabuilder.com](https://www.pwabuilder.com)에 배포한 주소(`https://내아이디.github.io/byeol-docs/`)를 넣고 **Start**
2. 점수 화면에서 매니페스트·서비스 워커가 인식되는지 확인 (이 앱은 둘 다 갖춰져 있어요)
3. **Package for stores → Android → Generate**
4. 내려받은 압축 파일 안의 `.apk`를 폰에 옮겨 설치해요. (폰 설정에서 “출처를 알 수 없는 앱 설치” 허용 필요)
5. 같은 압축 파일의 `signing.keystore`와 비밀번호는 **꼭 보관**하세요. 나중에 앱을 업데이트할 때 필요해요.

### 알아둘 점

- 하단/상단에 주소창이 보이면 “디지털 에셋 링크” 설정이 안 된 거예요. PWABuilder가 안내하는 `assetlinks.json`을 배포 사이트의 `.well-known/` 폴더에 올리면 사라져요. 개인용이면 주소창이 보여도 쓰는 데는 문제없어요.
- GitHub Pages가 `사용자.github.io/저장소이름/` 같은 하위 경로라서 `assetlinks.json`을 못 올리는 경우가 있어요. 그럴 땐 `사용자.github.io`(저장소 이름이 `사용자.github.io`) 저장소에 올리거나, 주소창이 보이는 상태로 쓰세요.
- 구글 플레이 스토어에 올리는 건 개발자 등록비(1회 $25)가 들어요. **개인 설치용 APK는 무료**예요.
- 문서 저장소는 앱과 브라우저가 서로 달라요. 브라우저에서 쓰던 문서를 앱으로 옮기려면 **백업 · 복원**을 쓰세요.

## 6. 컴퓨터에서 미리 써 보기

폴더에서 터미널을 열고 `python3 -m http.server 8000` → 브라우저에서 `http://localhost:8000`. (`index.html`을 더블클릭해서 `file://`로 열면 오프라인 기능이 빠지니 이 방법을 추천해요.)

## 파일 구성

```
index.html           화면 뼈대
style.css            디자인 (회색빛 흰 배경 + 검정 포인트 + y2k 별)
app.js               에디터·저장·내보내기·공유
config.js            공유 서버 주소/키 (선택)
supabase.sql         공유 서버 설정용 SQL (선택)
sw.js / manifest…    오프라인·앱 설치
fonts/               (직접 만들기) 아스타산스·느좋체 파일
```

## 알려진 한계

- 저장은 기기별이에요. 여러 기기 동기화는 지원하지 않아요 (필요하면 백업 파일로 옮기세요).
- 서식은 브라우저의 편집 기능 위에서 직접 만든 거라, 아주 긴 문서(수십만 자)에서는 느려질 수 있어요.
- 외부에서 복사해 온 글은 서식 없이 글자만 붙여 넣어져요. (앱 안에서 복사한 건 서식 유지)
- 표·이미지·목록은 아직 없어요.
